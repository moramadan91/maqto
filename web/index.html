03ماكتو + Claude

اكتب الفكرة، وشوف الفيديو بيتعمل قدامك.

ماكتو فيه مساعد جوه التطبيق وسيرفر MCP. Claude بيشتغل على التايملاين بتاعك لايف: يقص، يضيف نصوص وحركة وترانزيشن، يشوف الفريم ويراجع، ويصدّر.

المساعد جوه التطبيق

من غير تيرمنال ولا أوامر.

  1. ثبّت Claude Code وسجّل دخول بحسابك في Claude.
  2. في ماكتو دوس المساعد فوق.
  3. اكتب طلبك، زي «شيل السكتات» أو «حط عنوان في أول 3 ثواني»، وتابعه بيتعمل.

محتاج اشتراك Claude Pro أو أعلى. المساعد بيشتغل بحسابك إنت، ومش بيقدر يلمس أي ملفات على جهازك غير المشروع المفتوح.

المساعد
شيل السكتات وحط عنوان «عرض اليوم» في أول 3 ثواني get project update items add items preview تمام: شلت 4 سكتات (9.4 ثانية)، وحطيت «عرض اليوم» من 0 لـ 3 ثواني وراجعت الفريم.
عايز تعمل إيه؟

أو اربط ماكتو بـ Claude Code من التيرمنال:

الربط في ٤ خطوات

  1. نزّل ماكتو 1.0.6 أو أحدث. على الماك لازم يكون في Applications.
  2. ثبّت Claude Code وسجّل دخول بحسابك.
  3. افتح التيرمنال وشغّل أمر الربط اللي جنبك، مرة واحدة بس.
  4. افتح جلسة Claude Code جديدة واكتب طلبك، وقول فيه في ماكتو. أول مرة هيستأذن، اختار Allow always.

مش محتاج سلاش ولا تكتب كلمة MCP. لو الأدوات ما ظهرتش، اكتب /mcp في الجلسة واتأكد إن maqto قدامه connected.

أمر الربط

ماك (Terminal)

claude mcp add maqto -s user -- /Applications/Maqto.app/Contents/MacOS/maqto --mcp

ويندوز (PowerShell)

claude mcp add maqto -s user -- "$env:LOCALAPPDATA\Maqto\maqto.exe" --mcp

جرّب تكتب كده

اعمل في ماكتو فيديو موشن 9:16 مدته 8 ثواني عن مطعم برجر: خلفية متدرّجة، 3 جمل تدخل ورا بعض بحركة، وفي الآخر صدّره على الديسكتوب.

ماكتو بيفتح لوحده لو كان مقفول. وكل خطوة Claude بيعملها، تقدر ترجعها بـ Cmd/Ctrl+Z.

04التثبيت

دقيقة وتبدأ.

البرنامج مجاني ومش من متجر أبل أو مايكروسوفت، فالنظام هيسألك أول مرة بس.

ماك

  1. افتح ملف .dmg واسحب ماكتو لـ Applications.
  2. افتح ماكتو. لو ظهرت رسالة إنه مش من مطوّر معروف، دوس Done.
  3. روح System Settings → Privacy & Security وانزل لتحت ودوس Open Anyway.

ماك بمعالج Apple (M1 أو أحدث)، و macOS 13.4 أو أحدث.

ويندوز

  1. شغّل ملف setup.exe.
  2. لو ظهرت شاشة Windows protected your PC، دوس More info وبعدين Run anyway.
  3. اختار اللغة وكمّل التثبيت.

Windows 10 أو 11، 64-bit.

هو مجاني فعلاً؟

أيوه. من غير اشتراك، ومن غير إعلانات، ومن غير علامة مائية على الفيديو.

محتاج إنترنت؟

لا، المونتاج والتصدير بيشتغلوا من غير إنترنت. الإنترنت محتاجه بس للتحديثات، ولتحميل موديل الكابشن أول مرة (حوالي 550 ميجا للموديل المقترح).

بيشتغل على أنهي أجهزة؟

ماك بمعالج Apple (M1 أو أحدث) عليه macOS 13.4 أو أحدث، وويندوز 10 أو 11 بنظام 64-bit.

قص السكتات بيشتغل إزاي؟

عن طريق المساعد جوه ماكتو: تكتب «شيل السكتات» وClaude يلاقي الوقفات ويقصها على التايملاين. محتاج Claude Code واشتراك Claude Pro أو أعلى.

التحديثات بتوصل إزاي؟

أول ما تفتح البرنامج بيشوف لو فيه نسخة جديدة ويسألك. لو وافقت بيحمّلها ويقفل ويفتح تاني بالنسخة الجديدة.

فيديوهاتي بتترفع في أي مكان؟

لا. ملفاتك والصوت والتفريغ كله بيحصل على جهازك.
