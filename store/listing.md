## App Privacy (App Store Connect questionnaire)

Answer: **Data Not Collected.**
Why: there is no account, no analytics, no ads and no server of ours. Videos, projects and captions stay on the device. Speech recognition runs on the device with the downloaded model.
Network use: the app downloads the speech model (about 550 MB) from Hugging Face once, when the user first makes captions. That request sends no user data.

## Review notes (for Apple)

No login needed. To try captions: open a project with speech, tap Auto captions, then Arabic or English captions. The first run downloads the speech model (about 550 MB), then captions work offline.
